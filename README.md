# Google Developers Project 🚀

Welcome to the project repository for the Google Developers Bootcamp / Hackathon!

## 🌟 Tech Stack
- Frontend: HTML5, CSS3, Modern JavaScript
- APIs & Integration: Google Developer APIs (Gemini, Firebase, Cloud)
- Deployment: GitHub Pages / Vercel

## 🚀 Getting Started

### Local Setup
Open `index.html` directly in your browser or run a lightweight local server:

```bash
# Using Python
python3 -m http.server 8000

# Using npx serve
npx serve .
```

## 📦 Deployment
This project is configured for continuous deployment on GitHub Pages and Vercel.
